# Make the AI judge laugh

Entry for the make.fun bounty "Make the AI judge laugh"
(https://make.fun/bounty/ai-joke-03).

`main.py` writes one deterministic one-liner about AI coding agents
to `/output/entry.txt`. No network, no randomness, no model calls.

Run: `python3 main.py` (Python 3.13). Output: `/output/entry.txt`.
